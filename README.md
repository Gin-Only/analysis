# 古籍图像识别与文本分析算法

## 项目介绍

本项目是针对古籍文档图像进行自动化识别与分析的算法实现。古籍文献作为中华文化的重要载体，其数字化处理对于文化遗产保护与研究具有深远意义。然而，古籍图像通常面临版面复杂、字体风格多样、保存状况不一等挑战，传统OCR技术难以直接适用。本算法方案通过整合与优化先进的深度学习模型，构建了一套专门用于处理汉文古籍图像的完整流程，能够有效实现复杂版式下的文本检测、图像矫正、阅读顺序预测及端到端文字识别。

## 功能特点

- **任意形状文本检测**：采用先进的场景文本检测网络，精准定位古籍图像中不规则排列的文本列。
- **复杂版面阅读顺序预测**：结合编码解码网络与启发式规则，智能推断古籍页面的正确阅读顺序。
- **图像扭曲矫正**：针对古籍扫描中常见的形变与倾斜问题，利用图像处理技术实现文本区域的自动矫正，提升识别输入质量。
- **长文本序列识别优化**：对于过长的文本行图像，采用叠瓦式识别策略，避免因图像尺寸归一化造成的特征损失。
- **端到端文字识别**：使用改进的卷积循环神经网络模型，直接对文本图像进行序列识别，输出对应的文字内容。
- **流程集成与本地化**：提供完整的训练与推理脚本，并对竞赛代码进行了本地环境适配，便于研究与应用部署。

## 使用方法

### 环境配置


```shell
```

进入项目目录，安装所需的依赖库。建议使用Anaconda创建Python虚拟环境：

```shell
conda create -n ancient_ocr python=3.8
conda activate ancient_ocr
conda install pytorch torchvision cudatoolkit -c pytorch  # 请根据CUDA版本调整
pip install -r requirements.txt
```

最后，编译后处理所需的相关代码：

```shell
# 编译文本检测后处理模块
sh ./compile.sh
```

本项目包含多个可训练模块：

1.  **文本检测模型训练**
    ```shell

    ```
    请根据实际情况配置`train.sh`中的数据集路径与超参数。

2.  **文字识别模型训练**
    相关训练脚本与说明将在后续更新中提供。

3.  **辅助网络训练**
    用于图像预处理等任务的模型训练指引将逐步补充。

### 推理预测

使用以下命令对单张或批量古籍图像进行全流程推理：

```shell
sh infer.sh
```

您也可以直接运行主程序入口，进行本地化测试：

```shell
python main.py
```

对于单张图像的快速测试与调试，项目提供了灵活的脚本：

```python
# 在 TestModel.py 中，可通过修改 DEBUG 参数切换运行模式
# DEBUG = True   # 调试模式，输出详细中间结果
# DEBUG = False  # 加速推理模式
python TestModel.py --image_path /path/to/your/image.jpg
```

## 文件说明

- `main.py`: 项目主程序入口，集成了完整的处理流程，并适配本地运行环境。
- `TestModel.py`: 单张图像推理脚本，支持调试与快速推理两种模式。
- `Infer_Utils.py`: 核心工具模块，封装了图像投影分析、性质判断、几何矫正、叠瓦识别、顺序排序、模型加载等关键功能。
- `train_pan_pp/`: 文本检测模型训练相关代码与配置目录。
- `compile.sh`: 用于编译底层后处理算法的脚本。

## 算法流程概述

1.  **输入**：接收原始古籍文档图像。
2.  **文本检测**：定位图像中所有文本列区域。
3.  **区域矫正**：对每个检测出的文本区域进行几何形变矫正。
4.  **顺序预测**：分析矫正后区域的相对位置，预测符合古籍阅读习惯的序列顺序。
5.  **文本识别**：按预测顺序，对每个文本区域图像进行文字识别。
6.  **输出**：生成结构化的识别文本结果。
